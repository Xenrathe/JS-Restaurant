# README

## Legend's Treatery, a single-page application for a fictional restaurant

![Screenshot of About tab](https://github.com/Xenrathe/JS-Restaurant/blob/main/AboutTab.png?raw=true)

Legend's Treatery is a single-page application, in which each tab (About, Food, Drink) is its own separate module. The project was meant to demonstrate webpack & module structure with import/export.

Legend's Treatery is active on GitHub pages: (https://xenrathe.github.io/JS-Restaurant/)

### Features:

- Single Page Application - each tab is its own module
- Responsive design for tablet and desktop (mobile needs work)
- Tasty concoctions

### Tech Stack:

- CSS: Vanilla
- JS: Bundled via Webpack, including various plugins
- Backend: N/A - no backend

![Screenshot of Food tab](https://github.com/Xenrathe/JS-Restaurant/blob/main/FoodTab.png?raw=true)
